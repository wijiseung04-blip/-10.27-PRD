## 5. Build-Measure-Learn 실험 계획

실험 기간과 표본은 초기 운영을 위한 제안이며 확정된 사용자 조사 결과가 아니다. 각 실험은 학습을 얻을 수 있는 최소 규모로 진행하고, 결과 및 편향을 함께 기록한다.

### 실험 1 — 문제 발견 인터뷰
- 가설: H1
- Build: 한국어권에서 최근 영상을 제작한 1인·소규모 크리에이터를 대상으로 짧은 인터뷰 가이드를 준비한다. “썸네일 문구를 만들 때 마지막으로 겪은 어려움”, “실제로 한 행동”, “걸린 시간”, “기존 대안”을 묻는다.
- 대상·표본 제안: 적격 사용자 8~12명. 이 수는 학습을 시작하기 위한 제안이며 통계적 대표성을 뜻하지 않는다.
- Measure: 구체적인 최근 사례를 말한 사용자 수, 문제의 반복성·중요성, 실제 사용 대안, 제작 과정에서의 시간·불편 기록.
- 사전 판단 기준 제안: 인터뷰 대상의 절반 이상이 최근 사례와 현재 대안의 불만을 구체적으로 설명하면 다음 가치 실험을 진행한다. 미달이면 타깃이나 문제 정의를 수정한다. 기준은 모집 전에 재검토·고정한다.
- Learn / 다음 행동: 사용자가 실제로 묘사한 문제를 재정의한다. 문제 중요도가 낮으면 제품 가설을 피벗하거나 중단하고 기능 개발을 보류한다.
- 기간 제안: 모집 포함 1~2주.

### 실험 2 — 결과 품질과 사용 가치 테스트
- 가설: H2, H3
- Build: 자막 직접 입력과 제목 후보 생성을 제공하는 클릭 가능한 프로토타입 또는 수동 지원형(컨시어지) 테스트를 준비한다. 영상 제작자의 실제 자막을 사용하고, 입력 동의와 데이터 처리 방식을 안내한다.
- 대상·표본 제안: 실험 1과 별도로 모집한 적격 사용자 5~8명, 각자 실제 영상 한 편을 대상으로 과업을 수행한다.
- Measure: 생성 완료 여부, 후보별 내용 충실도와 차별성 평가, 후보 편집·복사 행동, 작업 시간, 후보를 쓰지 않은 이유.
- 사전 판단 기준 제안: 참가자 5명 중 4명 이상이 후보 하나 이상을 실제 작업에 맞게 편집 또는 복사하고, 내용 왜곡이 없는 후보를 확인할 수 있으면 MVP 개발을 계속한다. 안전하지 않거나 자막에 근거하지 않은 생성이 발견되면 해당 실패를 별도 차단 기준으로 기록하고 품질 개선 전 확장을 중지한다.
- Learn / 다음 행동: 활용되지 않은 후보의 공통 원인을 분류하고, 결과 품질·톤·입력 과정을 개선한다. 칭찬만 있고 실제 활용이 없으면 가설을 통과시키지 않는다.
- 기간 제안: 1주.

### 실험 3 — 수동 자막 입력의 마찰 확인
- 가설: H4
- Build: 앞선 과업 테스트에서 자막 텍스트 직접 입력만 제공하고, 작업 완료 여부와 중단 이유를 관찰한다.
- 대상·표본 제안: 과업 테스트 참여자 5~8명 또는 첫 사용 테스트의 적격 사용자.
- Measure: 자막 입력 시작·완료 비율, 입력에 걸린 시간, 자막을 구하지 못해 중단한 사례, URL 자동 수집을 요청한 맥락.
- 사전 판단 기준 제안: 참여자 절반 이상이 자막 준비를 이유로 핵심 과업을 완료하지 못하면 입력 마찰이 가치 검증을 가리는지 확인한다. 자동 수집은 별도 정책·기술 검토를 통과해야만 다음 범위로 편입한다.
- Learn / 다음 행동: 자막 붙여넣기를 유지·개선하거나, 허용된 자막 파일 입력 등 더 단순하고 적법한 대안을 검토한다.
- 기간 제안: 1주.

### 실험 4 — 초기 사용성 계측
- 가설: H3, 결과가 웹 MVP로 반복 제공될 때에도 사용 행동이 이어진다.
- Build: 제한된 공개 또는 초대형 MVP에 최소 이벤트 계측을 추가한다.
- Measure: 자막 제출 → 결과 표시 → 후보 편집·복사까지의 퍼널, 오류율, 완료 시간, 자발적 재사용 여부.
- 사전 판단 기준: 실험 2의 행동 기반 기준을 초기 기준선으로 삼고, 실제 유입량과 적격 사용자를 함께 공개한다. 충분한 관찰량을 정하기 전 전환율 목표를 확정하지 않는다.
- Learn / 다음 행동: 병목 단계 하나를 우선 개선하고, 변경 전후의 적격 사용자 행동을 비교한다. 유입이나 표본이 부족하면 결론을 보류한다.
- 기간 제안: 2~4주 또는 사전 합의한 유효 과업 수 달성 시점까지.
