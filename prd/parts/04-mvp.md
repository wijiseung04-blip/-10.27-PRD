## 4. MVP 범위와 사용자 흐름

### MVP가 답할 질문
자막 기반 제목 후보가 크리에이터의 실제 제목 작성 작업을 돕는가? 첫 검증에서는 자막 자동 수집보다 핵심 가치와 결과 품질에 집중한다.

### 핵심 사용자 여정
1. 사용자가 한국어 영상 자막 텍스트를 붙여 넣는다.
2. 앱이 비어 있지 않은 자막인지 확인하고 제목 생성 요청을 받는다.
3. 앱이 영상의 핵심 요약과 서로 다른 썸네일 제목 후보 5개를 제안한다.
4. 사용자가 후보의 적합성을 검토하고 필요하면 문구를 수정한다.
5. 사용자가 후보를 복사하거나, 부적합하다고 표시하고 이유를 남긴다.

### MVP 기능
- 자막 텍스트 직접 입력 및 길이·빈 입력 검증
- 자막 핵심 요약 1~2문장
- 영상 내용에 근거한 제목 후보 5개 생성
- 후보마다 서로 다른 관점 또는 표현을 제시하고 짧은 의도 표시
- 후보 텍스트 편집 및 복사
- 결과 유용성 및 내용 충실도에 대한 간단한 피드백
- 생성 중 표시, 중복 요청 방지, 실패 원인 안내 및 재시도

### 결과 품질 기준
- 자막에 없는 사실, 수치, 결과를 만들어내지 않는다.
- 제목은 짧고 한눈에 읽기 쉬운 표현을 지향하되, 기계적인 글자 수 제한으로 자연스러운 결과를 훼손하지 않는다.
- 사용자가 최종 문구를 검토하고 선택한다. 생성 결과는 게시 가능한 정답으로 보장하지 않는다.

### 첫 실험에서 제외
- URL에서 유튜브 자막 자동 수집: 플랫폼 정책·기술 검증 전 필수 흐름으로 두지 않는다.
- 다국어, 자막 파일 업로드, 사용자 계정과 저장 기록
- 이미지 생성·편집, 채널 분석, A/B 테스트 자동 실행, 직접 업로드
- 유료화, 팀 협업, 채널별 스타일 학습

### MVP 범위 변경 규칙
실험 결과에서 수동 자막 입력이 핵심 마찰로 반복 확인되면 자동 수집을 재검토한다. 핵심 가치가 확인되지 않은 상태에서 편의 기능을 추가해 문제를 가리지 않는다.
