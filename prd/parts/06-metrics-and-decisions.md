## 6. 성공 지표와 의사결정

### 핵심 학습 지표
**실제 후보 활용률**: 적격한 테스트 세션 중 사용자가 제목 후보 하나 이상을 편집하거나 복사한 세션의 비율. 생성 클릭이나 페이지 방문만으로 제품 가치를 판단하지 않는다.

### 보조 지표
- 입력 완료율: 유효한 자막 입력 후 생성 결과를 본 세션 비율
- 결과 도달 시간: 유효한 입력에서 결과 표시까지 걸린 시간
- 후보 품질 피드백: 자막 내용과의 일치도, 차별성, 실제 사용 가능성
- 실패율: 입력 오류, 생성 오류, 정책·기술상 URL 자막 취득 실패
- 재사용 신호: 같은 사용자가 다른 영상 자막으로 다시 작업한 비율

초기 기준선은 미정이다. 제안한 인터뷰·과업 실험에서 기준선을 확보하고, 표본 수·모집 방식·관찰 기간을 함께 기록한다. 조회수나 클릭률 변화는 제품 출시 전후의 다른 요인 영향을 분리하기 어려우므로 초기 성공 지표로 사용하지 않는다.

### 제안된 게이트
- **문제 게이트:** 문제 인터뷰에서 구체적이고 반복적인 제작 과업과 기존 대안의 불편이 확인되어야 가치 테스트로 진행한다.
- **가치 게이트:** 실험 2에서 사용자의 실제 편집·복사 행동 기준을 만족하고, 내용 충실도 실패가 통제 가능해야 MVP를 계속 개발한다.
- **입력 게이트:** 수동 자막 입력이 핵심 과업을 반복적으로 막는 경우에만 대안 입력 방식 탐색을 우선순위화한다.
- **확장 게이트:** 제한된 MVP에서 반복 사용과 안정성의 기준선을 확보한 후 자동 자막 수집, 사용자 계정, 추가 언어 등 확장을 검토한다.

### 지속·피벗·중단 결정
- 지속: 문제와 실제 활용 행동이 실험 기준을 충족하고, 품질·개인정보·정책 제약을 관리할 수 있다.
- 피벗: 사용자는 문제를 겪지만 제목 후보의 형식, 입력 방식, 핵심 타깃 중 하나가 맞지 않는다는 증거가 있다. 변경할 요소 하나를 정해 다음 실험을 한다.
- 중단 또는 보류: 반복 인터뷰에서 문제가 중요하지 않거나, 개선 후에도 실제 활용 행동이 관찰되지 않거나, 적법·신뢰성 있는 입력·생성 방식을 확보하지 못한다.

### 지표 운영 원칙
수치 임계치는 제안값과 관측 사실을 구분하고 실험 시작 전에 확정한다. 분모, 적격 사용자 정의, 제외 조건을 명시하며 소규모 표본에서 통계적 일반화를 주장하지 않는다.
