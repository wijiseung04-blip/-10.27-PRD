## 2. 대상 사용자와 문제

### 우선 사용자 가설
주요 대상은 영상 기획과 제작을 직접 하는 한국어권 유튜브 크리에이터, 특히 썸네일 문구 작성에 별도 담당자가 없는 1인 또는 소규모 제작자다. 이는 초기 타깃 가설이며, 인터뷰에서 확인한다.

### 해결하려는 사용자 과업
영상을 완성했거나 편집 중인 제작자는 영상의 핵심을 빠르게 되짚고, 영상의 내용과 어긋나지 않으면서 시선을 끌 제목 문구 몇 가지를 만든 뒤, 비교하고 최종 후보를 선택해야 한다.

### 문제 가설
1. 대상 제작자는 영상 내용을 요약하고 썸네일 문구를 만드는 데 반복적으로 시간을 쓴다.
2. 후보를 다양하게 만드는 과정에서 막히거나, 표현이 영상 내용과 맞는지 검토하는 부담을 느낀다.
3. 영상 전체를 재시청하거나 자막을 직접 훑는 대신, 자막 기반 도구의 제안을 받아 수정하는 방식을 유용하다고 느낄 수 있다.

위 내용은 검증 전 가정이며 사용자 조사 결과로 제시하지 않는다.

### 현재 대안과 확인할 질문
가능한 현재 대안은 직접 영상 재시청, 자막 검색, 팀원에게 의견 요청, 범용 AI에 영상 내용을 입력하는 방식이다. 인터뷰에서 실제 사용 중인 대안, 문제 발생 빈도, 소요 시간, 기존 대안의 불만을 질문한다.

### 초기 범위에서 제외할 사용자
영상 자막을 제공할 권한이 없거나, 제목 외에 썸네일 이미지 편집·채널 분석·게시 자동화를 우선적으로 원하는 사용자는 MVP 핵심 타깃이 아니다.
