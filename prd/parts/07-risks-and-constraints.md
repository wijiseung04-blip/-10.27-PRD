## 7. 위험, 제약, 미해결 질문

### 주요 위험과 대응
- **자막 내용 왜곡 또는 과장:** 생성 후보가 원문으로 뒷받침되는지 검토하고, 불확실한 내용의 과장 생성을 막는다. 사용자가 결과를 확인·수정하도록 한다.
- **자막 준비 마찰:** 첫 가치 테스트는 직접 붙여넣기로 범위를 제한하고, 입력 단계의 중단 사유를 측정한다.
- **유튜브 자막 자동 수집 정책·기술 제약:** MVP 기본 경로로 가정하지 않는다. 플랫폼 약관, API 조건, 저작권·개인정보 요건을 검토한 뒤 별도 결정한다.
- **외부 AI 처리에 따른 데이터 위험:** 실제 자막 전송 여부와 서비스 제공자, 보관·학습 조건을 확인하고 사용자에게 고지한다. 필요한 최소 데이터만 처리하고 불필요한 원문 로그를 남기지 않는다.
- **결과가 자극적이지만 부정확할 위험:** 클릭 유도보다 내용 충실도를 필수 품질 기준으로 둔다. 조회수 증가를 보장하지 않는다.
- **편향된 초기 검증:** 모집 경로와 참여자 특성을 기록하고, 친한 지인·얼리어답터의 긍정 반응을 전체 시장의 증거로 일반화하지 않는다.

### 비기능 및 운영 제약
- 키보드 접근과 모바일 화면 지원을 핵심 입력·결과 흐름에서 고려한다.
- 생성 중 상태, 명확한 오류, 재시도 경로를 제공한다.
- 자막 길이, 요청 빈도, 외부 서비스 장애를 고려하되 임의의 기술 스택을 본 PRD에서 확정하지 않는다.
- 서비스가 외부 모델 또는 API를 사용하면 비용·지연·가용성을 제한된 테스트에서 측정한다.

### 미해결 질문
1. 어느 유형의 크리에이터에게 제목 작성 문제가 가장 빈번하고 비용이 큰가?
2. 사용자는 영상 전체 요약, 핵심 장면 추출, 제목 후보 중 어느 결과에 가장 높은 가치를 두는가?
3. 사용자가 실제로 복사·수정할 수 있는 후보의 품질 기준은 무엇인가?
4. 목표 사용자가 자막을 쉽게 확보할 수 있는가, 아니면 입력 방식이 채택의 주요 장애물인가?
5. 자막 처리와 외부 모델 사용에 적용되는 동의, 보관, 정책 조건은 무엇인가?
